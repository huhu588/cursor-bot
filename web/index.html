    常用操作

    1. 设置路径：打开「本机 Cursor 补丁」，确认路径输入框。一般留空即可自动检测；若检测失败，填 Cursor.exe 或安装目录后点「设置路径」。
    2. 打补丁：点「打补丁」，非管理员会弹出 UAC。已适配 Cursor 3.17.21、3.18.x、3.19.7，会按本机版本自动选择锚点，旧版适配不会被卸掉。完成后请完全退出并重新打开 Cursor，再开始对话。
    3. 修复 DNS：若本机开着 Clash 等 fake-ip 代理，点「修复 DNS」写入 hosts；可用「查看补丁情况」确认 hosts 已修复。
    4. 探测本地账号：到「导入账号」点「探测本机账号」，把当前 Cursor 已登录的号加入列表（也可粘贴 token / 导入 JSON）。
    5. 打开 Cursor IDE 使用：在账号列表里点「切号」写入本机登录态，然后打开 Cursor 即可使用。需要换号时再切一次。
